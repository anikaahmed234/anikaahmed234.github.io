# Sultana Anika Ahmed Nayona Portfolio

Portfolio site for a Software Quality Assurance Engineer.

## Preview

This folder includes a ready-to-open static preview:

```sh
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080/
```

## Hugo

The Hugo source is also set up with the Celadon theme in `themes/celadon`.
After installing Hugo, run:

```sh
hugo server
```

Key files:

- `hugo.toml` - Hugo configuration and section order
- `data/profile.yaml` - hero profile, links, and highlights
- `data/projects.yaml` - selected project cards
- `data/skills.yaml` - QA skill cards
- `static/files/Sultana-Anika-Ahmed-Nayona-Resume.pdf` - downloadable resume
- `index.html`, `site.css`, `site.js` - static preview site
