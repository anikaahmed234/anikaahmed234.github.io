QA Showcase

Bugs I Found

Uncovered a critical race condition in a fintech payment gateway: concurrent deposit + withdrawal requests triggered double-debit on specific mobile networks. Found through exploratory testing on real devices — caught in staging before any customer was affected. Also surfaced a silent auth failure: expired JWT tokens returned HTTP 200 with an empty payload instead of 401, invisible to all existing monitoring and alerting tools.

1,200+ bugs reported 45+ critical blockers

Testing Strategy

Built risk-based testing strategies that prioritise high-impact user journeys — auth, payments, and data integrity — while using exploratory testing for new features. Structured test pyramids with unit coverage owned by devs, API contracts validated with Postman, and E2E regression owned by QA.

1,500+ test cases written Risk-based coverage

Production Issues Prevented

Flagged a broken OTP flow on iOS 17 that passed all Android tests — caught because real device testing was part of the release checklist. Intercepted a DB migration that would have silently truncated phone number fields for international numbers, found during pre-release data validation.

Zero P0 escapes (2+ yrs) Web · iOS · Android

Performance Benchmarks

Ran JMeter load tests simulating 1,000 concurrent users on the transaction API. Identified a bottleneck at the database connection pool (exhausted at 600 VUs) and collaborated with backend to tune limits — throughput improved 40% post-fix. Established baseline SLAs: P95 under 1s, P99 under 2s.

1,000 VU load tested 40% throughput gain

Automation Coverage

Built Cypress and Playwright automation suites covering 85%+ of critical user flows across 3 products. Integrated with CI/CD via GitHub Actions — suite runs on every PR, reports HTML results as artifacts, and blocks merges on failures. Reduced manual regression time from 3 days to under 45 minutes per release.

700+ automated tests 85%+ flow coverage

Lessons Learned

Emulators lie — real devices expose battery-saver mode, OEM overlays, and network interruptions that emulators mask. Never skip exploratory testing after automation passes: automation finds known bugs, exploration finds unknown ones. A defect found in dev costs 10× less than one found in production.
